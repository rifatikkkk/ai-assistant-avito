## **Документация по клиентской части**

### **Установка и запуск**

1. Выполнить клонирование клиентской части, выполнив `git clone https://github.com/rifatikkkk/ai-assistant-avito`
2. Установите зависимости, выполнив `npm install`
3. Запустите клиентскую часть - `npm run dev`

После этого клиентская часть будет запущен на порту 3000.
